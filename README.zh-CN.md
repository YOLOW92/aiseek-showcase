## 代表作品 / AiSeek

**一个帮助读者理解「变了什么、为什么重要、证据在哪里」的多语言信息平台。**

AiSeek 把重要变化、背景和出处放进同一个阅读体验。读者可以探索关联、关注对象，通过提醒和简报持续跟进。主站提供中文、英文和日文。

我发起这个项目，负责产品方向、需求、工程约束、验收决策与持续运营。本作品集聚焦信息平台主站。

## 亲自体验

从 [AiSeek](https://aiseek.dev/zh) 的一条变化开始，查看它引用的材料，再探索关联、关注对象或读一份简报。需要接入自己的工具，可以看[开发者指南](https://aiseek.dev/zh/developers)。

| 读者需求 | 已交付的产品入口 |
|---|---|
| 理解一件变化 | 变化、背景档案与原文段落 |
| 看关联和地点 | 结构视图与现有 SeekMap |
| 持续跟进 | 关注、提醒、简报与发布日历 |
| 接入其他工具 | 有账户额度的只读 API 与 MCP |

这些能力有产品更新记录，并对照[证据说明](proof/README.zh-CN.md)中记录的源码版本核验。它们不代表已测得的准确率、用户规模或收入；可用性和当前条款以主站为准。
