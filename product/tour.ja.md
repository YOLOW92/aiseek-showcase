# 三つの製品体験ルート

[ポートフォリオ](../README.ja.md) · [English](tour.md) · [简体中文](tour.zh-CN.md) · [日本語](tour.ja.md)

## 01 / 根拠をたどる

[AiSeek](https://aiseek.dev/ja) で公開済みの変化や背景記事を選び、支える原文を確認します。[方法説明](https://aiseek.dev/ja/method)で根拠の扱いを読み、[訂正記録](https://aiseek.dev/ja/corrections)で公開内容の修訂を確認できます。

**見る点：**主張から根拠へたどれること。

## 02 / 出来事から背景へ

既存の [SeekMap](https://aiseek.dev/ja/seekmap) で国を選び、関係する変化を調べます。対象と利用できる構造ビューへ進み、関係の背後にある主張を確認します。

**見る点：**地理と関係が理解を助け、仮説を確立した事実と区別できること。

## 03 / 読書を継続的な観察にする

[ブリーフ](https://aiseek.dev/ja/brief)や [Ahead カレンダー](https://aiseek.dev/ja/ahead)を読み、ログインして対象をフォローできます。連携には[開発者ガイド](https://aiseek.dev/ja/developers)から、アカウントのキーと枠に従って API や MCP を利用します。

**見る点：**再訪する理由と、読書から観察へ進む道筋。

## 体験を支える情報処理

![情報処理](../assets/diagrams/information.jpg)

文書から出来事と変化を整理し、主張と根拠が公開の境界を通って読者に届きます。非公開の調査はこの公開経路に入りません。
