## 読者の課題

重要な変化は言語、媒体、機関をまたいで届きます。必要なのは新たなフィードだけではなく、何が変わり、なぜ重要で、どの主張に根拠があり、何を追うべきかを理解することです。

## 製品の応え

AiSeek は技術、経済、政策などの重要な変化を整理し、背景、根拠、対象、継続的な観察を読書体験につなぎます。Research はこの体験を支え、対象プランの利用者に深い調査の機能を提供します。

| ユーザーの目的 | 製品の機能 |
|---|---|
| 変化を理解する | 変化と背景記事、原文の該当箇所 |
| 関係を調べる | 構造ビュー、対象の背景、既存の SeekMap |
| 継続して追う | フォロー、通知、ブリーフ、発表カレンダー |
| ツールを接続する | 利用枠のある読み取り専用 API と MCP |

英語・中国語・日本語に対応しています。方法、訂正、連絡先、クレジットを公開し、情報の扱いを確認できるようにしています。

## 次の方向

**AiSeek 2.0 は計画段階です。** SeekEarth は地理と時間から世界の変化を一貫して見る入口を目指し、SeekTrace は根拠の記録と履歴を追いやすくする方向です。製品の明確な中心と根拠の継続性を強める構想であり、上表の提供済み機能には含めていません。
