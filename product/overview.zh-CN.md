# Product / 从变化到理解

[作品集](../README.zh-CN.md) · [English](overview.md) · [简体中文](overview.zh-CN.md) · [日本語](overview.ja.md)

## 读者的问题

重要变化分散在不同语言、媒体和机构中。读者需要的不只是另一条信息流，而是看清变了什么、为什么重要、哪些主张有依据，以及什么值得继续观察。

## 产品如何回应

AiSeek 整理科技、经济、政策等领域的重要变化，把背景、证据、实体与后续跟进连接成阅读体验。Research 支撑这一体验，并为具备相应权益的用户提供更深入的工具。

| 用户任务 | 产品能力 |
|---|---|
| 理解变化 | 变化与背景档案，连接原文段落 |
| 探索关联 | 结构视图、实体背景与现有 SeekMap |
| 持续跟进 | 关注、提醒、简报与发布日历 |
| 接入自己的工具 | 有账户额度的只读 API 与 MCP |

产品提供中英日三语。公开的方法说明、更正记录、联系和鸣谢，让信息的处理方式可以被查看。

## 后续方向

**AiSeek 2.0 仍在规划。** SeekEarth 计划以地理和时间为轴，让变化中的世界有更连贯的观察入口；SeekTrace 计划让证据记录及其历史更容易追溯。它们回应的是产品缺少鲜明中心、证据连续性需要加强的问题，不属于上表已经交付的能力。
