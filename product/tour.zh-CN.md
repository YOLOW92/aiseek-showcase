# 三条产品体验路线

[作品集](../README.zh-CN.md) · [English](tour.md) · [简体中文](tour.zh-CN.md) · [日本語](tour.ja.md)

## 01 / 沿着证据阅读

打开 [AiSeek](https://aiseek.dev/zh)，选一条已发布变化或背景档案，查看支撑它的原文段落。[方法说明](https://aiseek.dev/zh/method)解释证据如何处理，[更正记录](https://aiseek.dev/zh/corrections)展示公开内容如何修订。

**观察重点：**从陈述到支撑材料的路径。

## 02 / 从一件事走向背景

打开现有 [SeekMap](https://aiseek.dev/zh/seekmap)，选择国家，查看相关变化。进入实体与可用的结构视图，再查看关系背后的主张。

**观察重点：**地理和关联是否帮助你理解信息，推测是否能与已确立的事实区分。

## 03 / 把阅读变成持续跟进

读一份[简报](https://aiseek.dev/zh/brief)，查看 [Ahead 日历](https://aiseek.dev/zh/ahead)，或登录关注对象。需要接入工具时，打开[开发者指南](https://aiseek.dev/zh/developers)，按账户密钥与额度使用 API 或 MCP。

**观察重点：**有没有回来的理由，以及从阅读到跟进的明确路径。
