## 提供済みの製品

多言語の公開閲覧、根拠の箇所と訂正記録、既存の SeekMap と構造ビュー、フォロー・通知・ブリーフ、購読、読み取り専用 API・MCP、ブラウザーのエラー収集。[サイト](https://aiseek.dev/ja)と[更新履歴](https://aiseek.dev/ja/changelog)から確認できます。

## 実装と検証の状況

| 作業 | 現在の段階 | 残る作業 |
|---|---|---|
| P55 評価基準 | 評価コードは実装済み | 所有者がラベルを確認し採点する |
| P63 構造と検出 | 構造分析の最初の部分を実装 | 60〜90 日の履歴で検出を評価する |
| P64 の後続作業 | 計画 | データに依存するラベル、対象、読書の作業 |
| P71 一次情報の変化 | 制裁リストは公開済み、法案・FDA はコード完成 | コード完成部分の運用検証 |
| P72 信頼性 | ブラウザーのエラー報告は公開済み | 公開前ブラウザー検査は削除され、現在は HTTP 検査を使用 |
| AiSeek 2.0 | 計画 | SeekEarth、SeekTrace と関連する製品作業 |

## 次に測るべきこと

| 問い | 必要な根拠 |
|---|---|
| 人が製品を見つけているか | 人とボットのアクセスを分け、読書と登録の経路を調べる |
| 読者が戻るか | 集団ごとの再訪と繰り返す観察の利用 |
| 有料の価値が続くか | 確認した購読、売上、継続的な有料利用 |
| 情報が役立つか | 確認した根拠・関連性の標本、訂正、利用者の意見 |
| 連携が日常の仕事を解決するか | 実際の作業に結びつく反復的な API/MCP 利用 |

これは次の段階の検証課題です。現在の事業概要は稼働する製品と実装済みの経路を基盤としています。
