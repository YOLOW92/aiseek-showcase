## 三个更能说明能力的选择

**一、不让模型自行认定事实。** 事实需要满足证据规则，缺乏支持的判断保持为假设。

**二、不把采集异常认定成世界热点。** 信息源的停更、暴增和时段差异都会扰动热度。系统因此加入了历史基线与信源变更识别。

**三、不为复杂而复杂。** 用 PostgreSQL 统一权威数据，控制模型调用预算，设计降级路径，在有限资源下保证产品持续运行。

我希望 AiSeek 证明的并非某个框架的熟练程度，而是**产品判断、AI 时代的技术组织能力、系统思维、问题解决与真实交付**。
