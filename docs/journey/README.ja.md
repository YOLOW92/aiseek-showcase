## コード量より重要な判断

**モデルの自信を事実認定に使わない。** 出典と明示された規則を優先し、未確認の内容は仮説として扱います。

**収集量の変化を世界の変化と混同しない。** 配信元の停止や増減、時刻の差による熱度の誤判定を抑える仕組みを設けました。

**無用な複雑さと費用を増やさない。** PostgreSQLを正本に、モデルの利用記録・予算・フォールバックを管理します。

この取り組みで示したいのは、**プロダクト判断、AI時代の開発マネジメント、システム思考と本番への継続的な納品力**です。
