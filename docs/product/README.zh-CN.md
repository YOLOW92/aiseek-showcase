## AiSeek 是什么？

AiSeek 是一个由个人独立主导开发、已经投入生产运行的**变化情报平台**。它在合法允许的范围内收集覆盖 24 个领域的公开信息，把变化组织成一条可检查的链路：**信号 → 证据 → 实体 → 关系 → 影响**。

它与普通新闻列表想回答的问题不同：**真正发生了什么变化？和哪些对象有关？这些判断的出处在哪里？**

### 一次完整的使用流程

1. **发现变化：** 从信号、每日简报、专题或深度报道找到值得关注的事件。
2. **核实出处：** 从论断跳转至原文证据、尽可能查看一手来源与更正记录。
3. **理解结构：** 查看企业公开关系、对象间连接路径，或者通过 SeekMap 观察地理关联。
4. **持续追踪：** 关注主题、回顾上次访问后的变化，并使用日历、通知和周报。
5. **开放集成：** 按订阅权益使用只读 API、MCP 及嵌入组件。

### 截至 P72 的五类产品能力

| 模块 | 已有能力 | 用户价值 |
|:--|:--|:--|
| **发现与报道** | 信号、每日简报、带出处的深度内容、更正机制 | 节省阅读时间，同时保持可追溯 |
| **结构分析** | 受控关系类型、企业关系、网络位置与限定范围的连接路径 | 看清事件背后的关联 |
| **SeekMap** | 国家层面的变化、时间/领域筛选、历史基线、单独标注的公开观测层 | 减少地图热度误读 |
| **研究与问答** | 流式研究流程、中日文引用核验等 | 辅助分析，同时展示不确定性 |
| **个人与开发者工具** | 关注、日历、通知、可安装网页、API、MCP、嵌入和订阅 | 让情报进入日常工作流 |

产品提供**中英日三种语言**，翻译在页面渲染之前完成，而非打开页面时临时调用模型。系统仍然存在模型和信源误差，不承诺所有内容必然准确。

### 一个使用场景（仅作示意）

假设官方公布了一项涉及半导体的贸易政策变化，读者除了看到标题，还可以尝试核对正式文件，区分“政策已发生”与“对供应链的推测影响”，进一步查看有关企业与技术的关系，并跟踪未来披露。此处是产品能力说明，**不是对具体企业的事实判断**。
