## AiSeek とは

AiSeek は、個人が主導して開発し、本番運用まで行った**変化インテリジェンス・プラットフォーム**です。利用が認められた公開情報を24分野から収集し、**シグナル → 根拠 → エンティティ → 関係 → 影響**という、検証できる流れに整理します。

通常のニュース一覧とは異なり、**何が変わったのか、何とつながるのか、その判断の出典は何か**を明らかにすることを目指します。

### 利用の流れ

1. **発見：** シグナル、日次ブリーフ、特集、詳報から変化を知る。
2. **確認：** 主張を根拠となる原文、一次情報、訂正履歴にたどる。
3. **構造を探索：** 企業の公開関係、エンティティ間の経路、SeekMapの地理的文脈を確認する。
4. **追跡：** フォロー、前回以降の変化、予定表、通知、週次まとめを利用する。
5. **連携：** 権限に応じて読み取り専用API、MCP、埋め込み機能を使う。

### P72時点の主な機能

| 領域 | 実装された機能 | 価値 |
|:--|:--|:--|
| **発見と詳報** | シグナル、日次ブリーフ、出典付き記事、訂正記録 | 情報収集時間を短縮し、検証可能性を維持 |
| **関係構造** | 管理された関係種別、企業ネットワーク、位置・経路分析 | 見出しの背後にある関係を把握 |
| **SeekMap** | 国別変化、絞り込み、履歴に基づく基準値、区別された観測レイヤー | ヒートマップの誤読を抑える |
| **Research / Ask** | 進捗を配信する研究フロー、中日文の引用確認 | 不確実性を残したまま調査を補助 |
| **個人・開発者向け** | フォロー、予定表、通知、インストール可能なWeb、API、MCP、埋め込み | 情報を他の作業にも活用 |

公開サイトは**日本語・英語・中国語**に対応。翻訳は描画前に用意し、ページ表示中にモデルを呼び出しません。ただし、情報源やモデルの誤りが完全になくなるわけではありません。

### 想定される使い方（説明用の例）

半導体に関する通商政策の公式発表があった場合、見出しだけでなく公式文書を確認し、決定された事実とサプライチェーンへの推論を区別し、関係企業を調べ、今後の発表を追跡することを目指します。**特定企業に対する事実認定ではありません。**
