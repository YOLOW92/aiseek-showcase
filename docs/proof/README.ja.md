## この版の対象

**2026年10月12日（日本時間）までのAiSeek 1.x、P0–P72。ゲーム開発が始まる前の機能を対象**とします。特定コミットをそのまま復元するものではなく、機能別にまとめた歴史的な公開資料です。ゲームおよびAiSeek 2.0は含みません。

以前の公開ショーケースで提供した次のコードは、**Git Blobを変えずに引き継ぎます**。

| ファイル | 検証できる点 | 注意 |
|:--|:--|:--|
| [`promote.ts`](../../proof/code/promote.ts) | 根拠からFACT / SUPPORTED / HYPOTHESISを判定する条件 | 非公開の共通型に依存し、単独実行不可 |
| [`relation-registry.ts`](../../proof/code/relation-registry.ts) | 関係種別とその型・時間の制約 | グラフ実装全体ではない |
| [`gate.py`](../../proof/code/gate.py) | 計算の受付と待機上限 | サービス全体ではない |

これらは**以前に公開された段階のコード**であり、P72時点でも全行が同一という保証ではありません。製品の中核ソースは非公開です。

## 主張と証拠の区別

| 主張 | 根拠 | 証明できないこと |
|:--|:--|:--|
| 多言語製品が公開された | 公開ウェブサイト | 稼働率保証、利用者数、収益 |
| 根拠による分類規則がある | 公開したコードと方法論 | すべての主張が正確であること |
| 関係種別が管理されている | レジストリと初期の47種類という記録 | 現実世界の関係の完全性 |
| P54–P72の機能進展 | 日付付き内部タスク記録と公開製品 | 第三者によるコード監査 |
| **10月6日当時の記録：740シグナル、13,337エンティティ、5,654関係、64,473根拠** | 旧ショーケースの自己申告値 | **P72の最新値、利用者数、売上ではない** |

在庫の件数は日付付きの**過去の自己記録**であり、今回独立検証していません。[旧コミット履歴](https://github.com/YOLOW92/aiseek-showcase/commit/4aa8243e0f958ef554927bb8cda83cfc54705665)で確認できます。

### 未完了事項を明確にする

- **P55：** 評価の枠組みを実装。手動ラベルと全面的な評価完了は主張しない。
- **P61：** 内部の位置サンプルでは正確な一致率が約 **64.0%から75.7%** に改善したとの記録。**地図全体の精度ではなく**、今回独立監査もしていない。
- **P63：** 関係ネットワーク分析の前半が完成。変化検出アルゴリズムの長期比較は未完了。
- **P64：** 読み、エンティティ統合、評価などは計画段階。
- **P71：** 制裁リストは稼働。その他の公的データ経路の一部は有効化待ち。
- **P72：** ブラウザーエラー報告を実装。リリース前ブラウザースモークテストは後に廃止。
- **P48：** API・MCP・配信用機能を実装。統一的なプロモーション開始は別判断。

## 訪問者数の図を載せない理由

今回Cloudflareの分析データを確認しましたが、**エッジのページビューは人間の訪問セッションではありません**。ブラウザー側の計測と差が大きく、ボットやリクエストを実ユーザー数とするのは不適切です。

P69で利用・転換経路を計測できるようになったことも、特定人数や収益の獲得を証明しません。照合していない成長率・転換率・売上は掲載しません。
