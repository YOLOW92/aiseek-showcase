## 解決したい課題

情報は豊富でも、**出典を確認できる文脈情報**は簡単に得られるとは限りません。ニュースは出来事を伝えますが、調査担当者、投資家、起業家、専門家は、何が重要で、どの組織や技術につながり、どこまで原典で確認できるのかを知りたいはずです。

AiSeekはその過程を一つの多言語製品にまとめることを目指します。これは**市場に関する仮説**であり、すでに市場で成功したという実績ではありません。

## 検証すべき差別化

| 代替手段 | 主な強み | AiSeekが目指す付加価値 |
|:--|:--|:--|
| ニュース集約・RSS | 速さと網羅性 | 原文の根拠とエンティティの関係 |
| 検索・AI回答 | 柔軟な検索と要約 | 証拠位置に紐づく主張、分類、訂正 |
| 金融端末・調査ツール | 専門データと成熟した機能 | 技術・政策・企業など分野横断の文脈 |
| 汎用知識グラフ | エンティティ間の接続 | 出典・時間・変化を伴う関係追跡 |

これは**カテゴリ別の概念比較**であり、競合を網羅的に調査した結果でも、他社に類似機能がないという主張でもありません。価値は継続利用・支払意向で検証する必要があります。

## P72までに構築した事業基盤

- **個人向けプラン：** 閲覧・研究などの権利を段階化し、Polarを課金基盤に採用。
- **開発者向け：** 読み取り専用API、MCP、埋め込み機能を提供。
- **組織向け協業：** データや研究ワークフローについて個別に相談可能。ただし契約売上を主張しない。
- **発信経路：** 三言語サイト、メール、公開チャンネル、共有機能。

本資料では**監査済み売上、有料転換率、顧客数、ARR、投資収益率は提示していません**。料金・権利は変更されるため[現行プラン](https://aiseek.dev/ja/pricing)をご覧ください。

## 実証できたことと今後の課題

| P72時点の成果 | 未検証の項目 |
|:--|:--|
| 多言語UIと本番運用プロセス | 継続的な集客・長期継続率 |
| 取得・根拠分類・関係分析 | 全分野における包括的な正確性 |
| Research・課金・API基盤 | 支払意向と持続可能な採算 |
| 費用・権限・情報源利用条件への対策 | 大規模負荷・商用ライセンスの拡張 |

### アクセス数を成果として強調しない理由

Cloudflareのエッジリクエスト数・ページビュー数を**実際の人間の訪問者数として扱うことはできません**。ブラウザー側の測定と大きく異なるため、この版では照合済みの利用者数や成長率を掲げません。収集した記事・関係・根拠の件数も利用者数ではありません。

## 募集中の機会

- **採用：** プロダクトエンジニアリング、テクニカルPM、AI活用開発、データプロダクト。
- **技術協業：** 適法な一次情報、検索、評価、グラフ、多言語処理。
- **研究・配信協業：** 出典を確認できる変化情報を他のワークフローに利用。
- **スポンサー・投資に関する対話：** 試験導入、事業適合性、支援について相談。

当時のAiSeekは**個人主導・自己資金のプロジェクト**であり、法人化や資金調達の成立を主張していません。
